# Quick Spam

A simple Python CLI tool to automate typing, mouse clicks, and custom key presses.

> **Note:** You may need to run this program as Administrator on Windows for keypresses and clicks to register properly across all applications.

---

### Features
* **Auto Clicker:** High-speed automated mouse clicking.
* **Text Spammer:** Fast automated typing for messages.
* **Random Text Spammer:** Random string generation and output.
* **Custom Button Spam:** Automated keypress loops for specific hotkeys.
